---
title: Platforms
description: The platforms XCSoar runs on, from Android and iOS devices and Kobo eReaders to Windows, macOS and Unix/Linux computers.
---

::field-group
  :::field{name="Android Devices"}
  XCSoar runs on Android 6.0 or newer. Many phones and tablets have a built-in
  GPS, a barometric pressure sensor, and an accelerometer (G-load) that XCSoar
  can use.
  :::

  :::field{name="iOS"}
  XCSoar runs on iPhone and iPad. Install it from the Apple App Store. Many of
  these devices have a barometric pressure sensor that XCSoar can use when
  present.
  :::

  :::field{name="eBookreader"}
  XCSoar runs on several Kobo eReader devices.
  :::

  :::field{name="Windows PC"}
  It is possible to run XCSoar on an ordinary computer with the Windows
  operating system. This setup can be used for training yourself in using
  XCSoar. A simulation mode is included in XCSoar as well as a IGC replay
  function, that can be used when not connected to a valid GPS source.
  :::

  :::field{name="macOS"}
  XCSoar runs on Apple Mac computers. Install it from the Apple App Store or
  from the XCSoar website.
  :::

  :::field{name="Unix/Linux PC"}
  XCSoar runs on Unix/Linux.
  :::
::
