## Navigation menu

| Menu page | Key 6 | Key 7 | Key 8 | Key 9 | Key 0 |
|---|---|---|---|---|---|
| **Nav 1/2** | [`Task`](/manual/tasks/task-modes) | [`Previous Turnpoint`](/manual/tasks/advancing-tasks) | [`Next Turnpoint`](/manual/tasks/advancing-tasks) | [`Waypoint List`](/manual/tasks/waypoint-selector) | [`Alternates`](/manual/tasks/abort-and-alternates#alternates) |

You should not start using XCSoar without knowing about the `Alternates`
feature. Any `Task` related item in the navigation menu is used for planned
cross country flight and certainly the second step.

## Configuration menu

| Menu page | Key 6 | Key 7 | Key 8 | Key 9 | Key 0 |
|---|---|---|---|---|---|
| **Config 1/3** | [`MacCready +`](/manual/glide-computer/speed-to-fly) | [`MacCready −`](/manual/glide-computer/speed-to-fly) | [`MacCready Auto`](/manual/glide-computer/auto-maccready) | [`Flight`](/manual/glide-computer/flight-setup) | [`Wind`](/manual/atmosphere/wind-settings) |
| **Config 2/3** | [`System`](/manual/configuration/configure-system) | [`Plane`](/manual/glide-computer/glide-polar) | [`Devices`](/manual/configuration/configure-devices) | `File Manager` | [`Replay`](/manual/tasks/logger#logger-replay) |
| **Config 3/3** | [`Logger Start`](/manual/tasks/logger) | [`Raw Logger`](/manual/tasks/logger#error-analysis-logger) | [`Airspace`](/manual/airspace/airspace-details#airspace-filter-dialogue) | `Vega` | `Profiles` |

The configuration menu is typically part of the ground interaction with XCSoar.
You are not expected to spend much time in-flight with tweaking the
configuration, except you manually adjust wind or MacCready settings. The `Vega`
item gives control over the Vega intelligent variometer. This comprises a
sub-menu.

## The Vega variometer sub-menu of the configuration menu

| Menu page | Key 6 | Key 7 | Key 8 | Key 9 | Key 0 |
|---|---|---|---|---|---|
| **Vega 1** | `Airframe Switches` | `Setup Audio` | `Manual Demo` | `Setup Stall` | `Accel` |

The functions in this sub-menu require the Vega intelligent variometer. The menu
can only be accessed if `Vega` is selected as the connected device.



## The pan mode sub-menu of the Display menu

| Menu page | Key 6 | Key 7 | Key 8 | Key 9 |
|---|---|---|---|---|
| **Pan** | [`Pan Off`](/manual/navigation/pan-mode) | `Zoom in` | `Zoom out` | `What's here?` |

This sub-menu unfortunately overlays the full-screen map view of the pan mode.
Its functions are quite evident, although the menu could be replaced by
multi-touch technology or knobs. Besides the essential exit pan mode function
the `What's here?` button offers brilliant access to the variety of information
of the map.
