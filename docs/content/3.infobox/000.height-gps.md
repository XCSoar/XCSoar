![InfoBox Simulator Keys](/img/figures/simulator-keys.png)

Altitude above mean sea level reported by the GPS. (Touch-screen/PC only) In
simulation mode this value is adjustable with the up/down arrow keys. The
right/left arrow keys also cause the glider to turn.

In simulator mode an additional dialogue is available to change the value of the
InfoBox.
