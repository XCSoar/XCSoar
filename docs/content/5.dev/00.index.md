Documentation for people building or hacking on XCSoar: compiling, dev
environment, architecture, policy, debugging utilities, Git tips, and more.

## File formats & configuration reference

These chapters are reference material: file layouts, syntax, and hooks.

- [Map file](/dev/map-file) — terrain, topography, airspace, and waypoint files
  XCSoar loads
- [Checklists](/dev/checklist) — checklist file format: paths, Markdown,
  checkboxes, and links (`https:`, `tel:`, `sms:`, `geo:`, `xcsoar://` dialogs,
  …)
- [Input events](/dev/input-events) — `.xci` mapping of keys, hardware buttons,
  and touch labels to actions; default F-key groups and glide-computer events
- [Lua](/dev/lua) — Lua API inside XCSoar for automation (often used with input
  events)

## Manufacturer protocols

- [Cambridge CAI302 Protocol](https://cambridge-aero.com/300series.htm) - 302
  Dataport User's Guide (PDF available from Cambridge Aero)
- [FLARM Data Port Interface ICD
  (FTD-012)](https://flarm.com/wp-content/uploads/2025/09/FTD-012-Data-Port-Interface-Control-Document-ICD-7.22.pdf) -
  FLARM protocol specification (PDF)
- [FLARM Downloads](https://flarm.com/support/downloads/) - Additional FLARM
  documentation
- [LX navigation
  Protocol](https://downloads.lxnavigation.com/details.php?id=17) - LX
