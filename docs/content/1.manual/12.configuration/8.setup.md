## Setup / Logger

The internal software logger has adjustable time steps, separate for
cruise and circling modes.
Typically the circling time step is set to a smaller value
than cruise in order to give good quality flight logs for replay
purposes.

::field-group
  :::field{name="Pilot name"}
  This is the pilot name used in the internal software logger
  declaration.
  :::

  :::field{name="Time step cruise*"}
  This is the time interval between logged points when
  not circling.
  :::

  :::field{name="Time step circling*"}
  This is the time interval between logged points when
  circling.
  :::

  :::field{name="Auto logger*"}
  Enables the automatic starting and stopping of the logger
  on takeoff and landing respectively. Disable when flying paragliders to
  prevent the low ground speeds from triggering the automatic logger.
  :::

  :::field{name="NMEA logger*"}
  Enable the NMEA logger on startup? If this option is disabled,
  the NMEA logger can still be started manually.
  :::

  :::field{name="Log book*"}
  Logs each start and landing.
  :::

  :::field{name="Logger ID"}
  This is the logger registration.
  :::
::

## Setup / Units

This page allows you to set the units preferences used in all
displays, InfoBoxes, dialogues and input fields.
For most users hopefully one of the presets will match the needs.  The presets
include unit sets for **American**, **Australian**, **British**,
and **European**.

Separate selections are available for all items. Once you changed a given
preset it will be referenced as ‘Custom’ set and will also be stored in your
profile.

::field-group
  :::field{name="Aircraft/Wind speed*"}
  Units used for airspeed and ground speed: mph,
  knots, km/h. A separate unit is available for task speeds.
  :::

  :::field{name="Distance*"}
  Units used for horizontal distances e.g. range to waypoint,
  distance to go: sm, nm, km.
  :::

  :::field{name="Lift*"}
  Units used for vertical speeds (variometer): knots, m/s, ft/min.
  :::

  :::field{name="Altitude*"}
  Units used for altitude and heights: ft, m.
  :::

  :::field{name="Temperature*"}
  Units used for temperature: °C, °F.
  :::

  :::field{name="Task speed*"}
  Units used for task speed: mph, knots, km/h.
  :::

  :::field{name="Pressure*"}
  Units used for pressures: hPa, mb, inHg.
  :::

  :::field{name="Lat./Lon.*"}
  Units, or better formats used for latitude and longitude.
  Supported are several ‘degree/minutes/seconds’ formats, respectively
  their decimal fraction, and the  UTM WGS 84 format.
  :::
::

## Setup / Time

Set the local time offset with respect to UTC.

::field-group
  :::field{name="Automatic UTC offset"}
  If enabled, the UTC offset is taken from the time zone
  configured in the operating system and is kept up to date, so it follows
  daylight saving time changes and travelling to another time zone.  Disable
  this option to enter the offset manually.
  :::

  :::field{name="UTC offset"}
  The field allows the UTC local time offset to be specified.  It is
  only editable while ‘Automatic UTC offset’ is disabled.
  :::

  :::field{name="Local time"}
  The local time is displayed below in order to make it easier to verify
  the correct offset has been entered.  Offsets to the quarter-hour may be
  set.
  :::

  :::field{name="Use GPS time*"}
  This option, if enabled sets the clock of the computer to
  the GPS time once a fix is set. This is only necessary if your computer
  does not have a real-time clock with battery backup or your computer
  frequently runs out of battery power or otherwise loses time.
  :::
::

## Setup / Tracking

‘*Live*’-Tracking means using a GPS to determine your position and a mobile
network to send this position in real-time to a server, other people can see
your exact position and track presented in a map just in time.
The tracking option needs the capability to connect to mobile networking as
offered by your glide computer.

Currently there are two tracking protocols implemented. ‘*SkyLines*’ as a spin
off project from XCSoar itself; for details on this service have a look at
https://skylines.aero.
And also the ‘*LiveTrack24*’ protocol used e.g. by the tracking
portal on http://www.livetrack24.com.
Please consult the web pages of the service provider listed under ‘Server’
for details on this setup.

::field-group
  :::field{name="SkyLines"}
  Switch this **On** to enable the live stream of
  your position to ‘*SkyLines*’.
  :::

  :::field{name="Tracking Interval"}
  The time interval for which one position is sent to
  the tracking service. ‘*SkyLines*’ implements a very lean protocol, so that
  even a 30 sec. interval does not exhaust a plain GPRS connection (ca.
  12 kbit/sec).
  :::

  :::field{name="Key"}
  Create a key on the page https://skylines.aero/tracking/info
  and enter it here, to identify your positions at the tracking service.
  :::

  :::field{name="LiveTrack24"}
  Switch this **On** to enable the live stream of
  your position to ‘*LiveTrack24*’.
  :::

  :::field{name="Tracking Interval"}
  The time interval for which one position is sent to
  the tracking service.
  :::

  :::field{name="Vehicle Type"}
  Type of vehicle used.
  :::

  :::field{name="Server"}
  The service’s web address to stream your position to. There is currently
  a choice of some predefined.
  :::

  :::field{name="Username"}
  If you created an account you can enter those credentials here.
  Otherwise the track will be logged as ‘*guest*’ and thus be anonymous.
  :::

  :::field{name="Password"}
  The password to your tracking account.
  :::
::
