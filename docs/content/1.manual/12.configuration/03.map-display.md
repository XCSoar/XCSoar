## Map Display / Orientation

This page let you specify the favoured map orientation and view.

::field-group
  :::field{name="Cruise/Circling orientation" #conf-orientation}
  This determines how
  the screen is rotated with the glider, depending on it’s current display
  mode.

  * **Track up**: The moving map display will be rotated so the glider’s track
    is oriented up. The north arrow symbol points to true north. The glider
    symbol may be shown rotated according to the computed heading of the
    glider taking wind into account.
  * **Heading up**: The moving map display will be rotated so the glider’s
    heading is oriented up.
  * **North up**: The moving map display will always be orientated true north
    to south and the glider icon will be rotated to show its course (corrected
    for wind).
  * **Target up**: The moving map display will be rotated so the current
    target direction is oriented up.
  * **Wind up** The moving map display will be rotated so the wind is always
    oriented top-down (might be useful for wave flying).

  ![Map orientation](/img/figures/config-map_projection.png)
  :::

  :::field{name="Circling zoom" #conf-circlingzoom}
  This determines whether separate
  zoom levels will be maintained for circling and cruise modes.  If enabled,
  then the map will zoom in automatically when entering circling mode and zoom
  out automatically when leaving circling mode.
  :::

  :::field{name="Map shift reference"}
  The direction according to the map will be displaced
  in order to present a meaningful map section.

  * **None**: Disable any adjustment.
  * **Track**: Use a recent average of the ground track as basis.
  * **Target**: Use the current target waypoint as basis.
  :::

  :::field{name="Glider position offset" #conf-gliderposition}
  Defines the location of the
  glider drawn on the screen in percent from the screen edge.
  :::

  :::field{name="Max. auto zoom distance"}
  The upper limit for auto zoom distance.
  :::
::

## Map Display / Elements

This page provides options relating to screen elements overlayed to the map
display.

::field-group
  :::field{name="Ground track"}
  Display the ground track (ground track projection) on the map.
  The setting “Auto” displays the ground track only if there is a significant
  difference to plane heading.
  :::

  :::field{name="FLARM traffic" #conf-flarm-on-map}
  This enables the display of FLARM
  traffic on the map.
  :::

  :::field{name="Trail length*" #conf-snailtrail}
  Determines whether and how long a
  snail trail is drawn behind the glider.

  * **Off**: No trail is drawn.
  * **Long**: A long trail is drawn (approx 60 minutes).
  * **Short**: A short trail is drawn (approx 10 minutes).
  * **Full**: A trail for the entire flight is drawn.

  ![Map elements](/img/figures/config-map_elements.png)
  :::

  :::field{name="Trail drift*" #conf-traildrift}
  Determines whether the
  snail trail is drifted with the wind when displayed in circling mode.
  Switched Off, the snail trail stays uncompensated for wind drift.
  :::

  :::field{name="Trail type*" #conf-snailtype}
  Sets the type of the snail trail display.

  * **Vario #1**: Within lift areas lines get displayed green and
    thicker, while sinking lines are shown brown and thin.  Zero lift
    is presented as a grey line.
  * **Vario #1 (with dots)**: The same colour scheme as the previous, but
    with dotted lines while sinking.
  * **Vario #2**: The climb colour for this scheme is orange to red, sinking
    is displayed as light blue to dark blue. Zero lift is presented as a
    yellow line.
  * **Vario #2 (with dots)**: The same colour scheme as the previous, but
    with dotted lines while sinking.
  * **Altitude**: The colour scheme corresponds to the altitude.
  :::

  :::field{name="Trail scaled*" #conf-trailscaled}
  If set to ON the snail trail
  width is scaled according to the vario signal.
  :::

  :::field{name="Detour cost markers*"}
  If enabled this displays in cruise flight some
  figures projected in front of the nose of the glider icon.  This is the
  additional distance in percent if you fly up the position of the figure and
  after that again straight towards the target, compared to the straight
  distance to target.
  :::

  :::field{name="Aircraft symbol*"}
  Sets the symbol used for the aircraft.

  * **Simple**: Simplified line graphics, a black glider shape with white
    contours.
  * **Simple (large)**: Enlarged simple graphics for better visibility on a
    small display.
  * **Detailed**: Rendered aircraft graphics.
  * **HangGlider**: Simplified hang glider as line graphics, white with black
    contours.
  * **ParaGlider**: Simplified para glider as line graphics, white with black
    contours.
  :::

  :::field{name="Wind arrow*"}
  Determines the way the wind arrow is drawn on the map.

  * **Off**: No wind arrow is drawn.
  * **Arrow head**: Draws an arrow head only.
  * **Full arrow**: Draws an arrow head with a dashed arrow line.
  :::

  :::field{name="FAI triangle areas"}
  Whether to show FAI triangle areas on the map.
  :::
::

## Map Display / Waypoints

This page provides options for how waypoints are displayed on the map.

::field-group
  :::field{name="Label format" #conf-labels}
  This setting determines the label format
  displayed with each waypoint. There are four different format options.

  * **Full name**: The full name of each waypoint is displayed.
  * **First word of name**: Only the first word (up to the first space) of
    the waypoint name is displayed.
  * **First 3 letters**: The first 3 letters of the waypoint name are
    displayed.
  * **First 5 letters**: The first 5 letters of the waypoint name are
    displayed.
  * **None**: No name is displayed with the waypoint.

  ![Waypoint display](/img/figures/config-map_waypoint.png)
  :::

  :::field{name="Arrival height*" #conf-arrivalheight}
  This setting allows arrival height
  and/or required glide ratio to also be shown in labels for landable
  waypoints. See Section [Waypoints](/manual/navigation/waypoints) for
  more information.

  * **None**: Neither arrival height nor required glide ratio is displayed.
  * **Straight glide**: Straight glide arrival height (no terrain is
    considered). (default option)
  * **Terrain avoidance glide**: Arrival height considering any detour
    needed to avoid terrain.
  * **Straight & terrain glide**: Both arrival heights.
  * **Required glide ratio**: Glide ratio over the ground required to reach
    the waypoint.
  * **Required GR & terrain glide**: Both required glide ratio and terrain
    avoidance glide arrival height.

  For any option including terrain avoidance glide arrival height, the ‘Reach
  mode’ setting (on the ‘Glide Computer / Route’ configuration page,
  [Glide Computer / Route](/manual/configuration/glide-computer#glide-computer-route))
  must be set to ‘Turning’.

  Glide ratio will be shown whenever the aircraft is higher than the waypoint
  regardless of how shallow the glide is and
  regardless of which configured waypoint file contains the waypoint. Negative
  straight glide arrival heights, however, will only be shown for
  waypoints in the ‘Watched waypoints’ file (selected on the
  ‘Site Files / Site Files’ configuration page,
  [Site Files](/manual/configuration/site-files)). Negative
  *terrain avoidance* arrival heights will never be shown for any waypoints.

  ::warning
  Also, if the ‘Straight & terrain glide’ option is selected and only one
  arrival height (a positive one) is shown for a waypoint (e.g.,
  ‘Moontown:100m’), either no detour around terrain is needed or there’s
  interfering terrain and no possible detour will get you to the waypoint at
  an acceptable height (the configured safety ‘Arrival height’
  ([Glide Computer / Safety Factors](/manual/configuration/glide-computer#glide-computer-safety-factors))
  above the ground at the waypoint). These are two
  *very different situations* safety-wise!
  Use other clues, like the reach line or the waypoint
  appearance (e.g., color), to determine which is the case in this scenario.
  Both arrival altitudes will be shown only if there’s a detour that
  will get you there at an acceptable height but a direct route is blocked
  by terrain.
  For example, ‘Moontown:200/50m’ means (1) you could reach Moontown 200m
  above the minimum acceptable height if not for terrain that’s in your way
  but (2) there’s a detour that will get you there 50m above the minimum
  acceptable height. So in this case, you must detour, and the detour will
  cost you 150m (compared to if there were no terrain in your way).
  ::
  :::

  :::field{name="Label style*"}
  Labels for landables can be shown on a rounded rectangle with
  white background, or with outlined letters.
  :::

  :::field{name="Waypoint label visibility*" #conf-labelvisibility}
  Controls which waypoints
  are displayed with names and arrival altitudes on the map:

  * **All**: All waypoint labels will be displayed.
  * **Task waypoints and landables**: All waypoints part of a task and all
    landables will be displayed.
  * **Task waypoints**: All waypoints part of a task will be displayed.
  * **None**:  No waypoint labels will be displayed.
  :::

  :::field{name="Landable symbols" #conf-waypointicons}
  Three styles are available:
  Purple circles (WinPilot style), a high contrast style with icons,
  and icons with a traffic light colour scheme. See Section
  [Waypoints](/manual/navigation/waypoints) for details.
  :::

  :::field{name="Detailed landables*"}
  Enabling details on landables displays instead of fixed icons
  variable information like runway length and heading.
  :::

  :::field{name="Landable size*"}
  A percentage to select the size landables are displayed on the map.
  :::

  :::field{name="Scale runway length*"}
  Enabling this option will display for detailed landables
  additionally a scaled runway length based on real length.
  :::
::

## Map Display / Terrain

This page sets how terrain and topography is drawn on the map window. The
effect of the changed terrain settings are directly visible at the small
preview below.

![Terrain configuration](/img/figures/config-terrain.png)

::field-group
  :::field{name="Terrain display"}
  Draws digital elevation terrain on the map.
  :::

  :::field{name="Topography display"}
  Draws topographical features (roads, rivers, lakes etc.) on
  the map.
  :::

  :::field{name="Terrain colours"}
  Defines the colour ramp used in terrain rendering.  Various
  schemes are available, which works best for you will depend on how
  mountainous your region is.
  :::

  :::field{name="Slope shading*" #conf-shading}
  The terrain can be shaded to indicate slopes and
  other terrain features. The illumination direction for the shading can be
  either: geographically fixed from the north-west, screen-relative fixed
  from the top left, or the shading can be according to the actual current
  sun position. In addition, the illumination can be set to indicate
  the wind direction, with upwind slopes bright, and downwind slopes shaded.
  :::

  :::field{name="Terrain contrast*"}
  Defines the amount of Phong shading in the terrain rendering.
  Use large values to emphasise terrain slope, smaller values if flying in
  steep mountains.
  :::

  :::field{name="Terrain brightness*"}
  Defines the brightness (whiteness) of the terrain rendering.
  This controls the average illumination of the terrain.
  :::

  :::field{name="Contours*"}
  Draws contour lines on the terrain.  Two groups of
  modes are available.
  The adaptive modes (**Mountains**, **Highlands**, **Lowlands**,
  **Superfine**) set a base line density that is automatically scaled
  with the zoom level to avoid over-cluttering at small scales.
  **Mountains** is for areas with steep slopes, with a 256 m base
  spacing; the other adaptive modes provide progressively smaller
  spacing and higher line density.
  The fixed modes (**Fixed 256 m**, **Fixed 128 m**,
  **Fixed 64 m**) use a constant contour spacing regardless of zoom
  level.
  :::
::

## Map Display / Airspace

This page is used to determine how the airspace information is
displayed and how warnings are issued.

::field-group
  :::field{name="Airspace display"}
  Controls how airspace display and warnings are filtered
  based on altitude.  The airspace filter dialogue also allows filtering
  of display and warnings independently for each airspace class.

  * **All on**: All the airspace information is displayed at the same time.
  * **Clip**: Only airspace below a user determined altitude is shown.
  * **Auto**: Only airspace at the current altitude plus or minus a user
    definable margin is shown.
  * **All below**:  Like auto plus every airspace below the glider is shown.

  ![Airspace configuration](/img/figures/config-airspace.png)
  :::

  :::field{name="Clip altitude"}
  For clip mode, this is the altitude below which airspace
  is displayed.
  :::

  :::field{name="Margin"}
  For auto and all below airspace mode, this is the height
  above/below which airspace is included.
  :::

  :::field{name="Warnings"}
  Determines whether warnings are enabled or disabled.
  :::

  :::field{name="Warning time*"}
  This is the time before an incursion is estimated at
  which the system will warn the pilot.
  :::

  :::field{name="Acknowledge time*"}
  This is the time period in which an acknowledged airspace
  warning will not be repeated.
  :::

  :::field{name="Use black outline*"}
  Draws a black outline around each airspace.
  :::

  :::field{name="Airspace fill mode*"}
  Specifies the mode for filling the airspace area.

  * **Fill all**:  Transparently fills the airspace colour over the whole
    area.
  * **Fill padding**: Draws a solid outline with a half transparent border
    around the airspace.
  * **Default**:  This selects the best performing option for your hardware.
    In fact it favours ‘*Fill padding*’.
  :::

  :::field{name="Airspace transparency*"}
  If enabled, then airspaces are filled transparently.
  :::
::

This page also has `Colours` and `Filter` buttons which
can be used to review or change the colours/patterns used by each
airspace class, and whether each airspace class will be filtered out
of warnings and/or display. Depending on the airspace transparency setting it
is no longer needed to define patterns. The availability of transparency
relies on the capabilities of the used hardware and may differ.

### Colours

This function is used to determine the colours used to draw each class of
airspaces.

First select the airspace class you wish to change. Then select the colour and
pattern you wish the selected airspace class to be drawn in.

### Filters

The filter function is described in Section
[Airspace filter dialogue](/manual/airspace/airspace-query-and-details#airspace-filter-dialogue).

### NOTAM

This page configures downloading and display of NOTAM affected areas.
NOTAMs are shown as airspaces on the map and are intended for
situational awareness only; they do not replace a proper NOTAM briefing.
See Section
[NOTAM airspace](/manual/airspace/airspace-display#notam-airspace).

::field-group
  :::field{name="NOTAM Support"}
  Enables downloading and display of NOTAMs from
  aviation authorities.
  :::

  :::field{name="API URL"}
  Base URL of the NOTAM proxy API.
  :::

  :::field{name="Search Radius"}
  Radius around the current location for which NOTAMs
  are downloaded.  If the aircraft moves outside the loaded area and
  Internet access is available, XCSoar downloads NOTAMs for the new area.
  :::

  :::field{name="Auto-Refresh (minutes)"}
  Time interval for automatic NOTAM updates.
  Set this to 0 to disable automatic refresh and use manual refresh only.
  :::

  :::field{name="Show IFR-Only NOTAMs"}
  Includes NOTAMs marked as IFR-only traffic.
  This is disabled by default.
  :::

  :::field{name="Show Only Currently Effective"}
  Hides NOTAMs which are not effective
  at the current time.  This is enabled by default.
  :::

  :::field{name="Maximum NOTAM Radius"}
  Hides NOTAMs whose affected radius is larger
  than this value.  Set this to 0 to disable the radius filter.  The
  default is 100 km.
  :::

  :::field{name="Hidden Q-Codes"}
  Space-separated list of Q-code prefixes to hide.
  Prefixes are matched case-insensitively.  The default list is
  `QA QK QN QOL QOA QOBTT`, hiding administrative, checklist,
  navigation-aid and obstacle-lighting or obstacle-administration notices.
  :::
::

The read-only rows below the filter settings show how many loaded NOTAMs
are currently filtered by each filter.  The `Refresh` button saves
the current settings and requests a new download for the current
position.  The `List` button opens the current NOTAM list for
review.
