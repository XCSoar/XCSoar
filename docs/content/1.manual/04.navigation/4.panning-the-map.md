---
title: Panning the map
description: Using pan mode to explore the map beyond the glider, and how to enable and leave it.
---

A pan mode allows the user to explore areas beyond the glider.  This
is particularly useful when task planning.

`Display 1` → `Pan On`

1. Enable pan mode by button menu or by gesture.  The gesture for this is
   moving your fingertip up, right, down, left, supposed to form a “P”.
   :gesture{id="URDL" size="sm"}
2. The map can then be panned by dragging the screen or using the cursor
   keys.
3. When done, pan mode has to be disabled manually, by pressing ‘*Pan Off*’
   from the special sub-menu of buttons in pan mode.

![Pan mode](/img/figures/pan.png)

When pan is active, the letters ‘PAN’ appears next to the map scale.  While
panning the location of the focus stays in the middle of the display under the
cross hairs.

Despite the focus under the cross-hairs the map
still offers the ‘*What’s here?*’ feature just by touching any
position on the map (presuming a touch-screen).
