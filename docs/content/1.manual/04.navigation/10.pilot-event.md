---
title: Pilot Event
description: Marking pilot events, announcing them to loggers, and the PEV start procedure for task starts.
---

A Pilot Event (PEV) system allows pilots to mark particular times during a
flight, such when inside a Turn Point Observation Zone (TP OZ). Also, when
configured, it allows to initiate a special *Pilot Event* task start
protocol[^1].

`Nav 2` → `Pilot Event`

When pressed, XCSoar will internally track the window open and close times,
according to configuration defined in Task Rules (See
[Racing](/manual/cross-country-tasks/task-types#racing)): start
window will open after *PEV start wait time*
([Task Defaults / Task Rules](/manual/configuration/task-defaults#task-defaults-task-rules))
minutes and will be open for *PEV start window* minutes. The start open/close
countdown will be displayed in the *Start open* and *Start reach*
infoboxes. Make sure to have one/both visible to effectively calculate your
start.

Also, *Pilot Event* will be announced to connected devices, allowing loggers to
register it without pilot pressing the physical button on the logger device
itself. This might be useful when logger is located outside of pilot reach
(e.g. behind the panel). It is recommended to check on your device’s manual
whether it supports external PEV declaration -some older loggers may not-.

In order to start a task when *Pilot Event Start* is used, press the
*Pilot Event* button, wait for *PEV start wait time* and then cross the
start line within *PEV start window* minutes.

::tip
It may be useful to have *Start open* and/or *Start reach*
InfoBoxes visible to effectively use the *PEV Start* procedure.
::

::tip
Note that the start window created by pressing the *Pilot Event*
is “soft”, as it is only informative to the pilot via the infoboxes mentioned
above. XCSoar will still compute a valid start if one is performed outside of
the PEV window -just like it would be scored in a competition-. In contrast,
the task settings *Start open/close time* in
[Racing](/manual/cross-country-tasks/task-types#racing) define
a “hard” window, outside of which a start will not be computed.
::

[^1]: PEV start procedure may be used in competitions to reduce
    mass starts, gaggles and following.
