---
title: Weather forecast, EDL Soaring
description: Wave weather overlays from the EDL Soaring MBTiles service, their cache management and page setup.
---

XCSoar can display wave-oriented weather overlays provided by the
public EDL Soaring MBTiles service at
https://www.edl-soaring.com/mbtiles/.  XCSoar downloads the
tiles on demand from EDL Soaring’s public extraction service and stores
them locally as `.mbtiles` files in the weather cache.

Before using EDL, enable *EDL Weather Page* in the system
configuration under *System setup / Weather* (requires an OpenGL build
with HTTP support).

Tiles are cached locally.  Open the `EDL` tab in
`Info` → `Weather` or the EDL section in
*System setup / Weather* to manage the cache:

::field-group
  :::field{name="Cached day"}
  Show which UTC days are already stored in the local
  cache.  A day is marked *Complete* when all 24 forecast hours and
  all five EDL levels are available locally, otherwise it is marked
  *Partial*.
  :::

  :::field{name="Precache day"}
  Download all 24 hours and all five EDL levels for
  the selected UTC day.  This is intended for pre-flight preparation, so
  that the EDL data remains available when internet connectivity is lost
  in flight.
  :::

  :::field{name="Clean other days"}
  Keep only the selected cached UTC day and delete
  the other locally cached EDL days.
  :::
::

Configure a map page in the page configuration dialogue
(Section
[Look / InfoBox Pages](/manual/configuration/look#look-infobox-pages-or-just-pages)):
set *Main area* to *Map*
(or *Map (north-up)*), *Map overlay* to *EDL*, and
*Bottom area* to *Weather controls*.  The in-flight bottom
panel provides:

::field-group
  :::field{name="Auto advance"}
  When enabled, XCSoar follows the next UTC forecast
  hour and selects the lowest isobar above the current aircraft
  altitude.  Forecast and level selectors are disabled while auto advance
  is active.
  :::

  :::field{name="Forecast"}
  Select the forecast hour to display.  XCSoar shows this
  time in local time for the pilot’s convenience, but requests the data
  from the EDL service in UTC because the remote service expects UTC
  timestamps.
  :::

  :::field{name="Level"}
  Select one of the supported pressure levels.  The EDL
  source provides the fixed isobars 500, 600, 700, 800 and 900 hPa.
  XCSoar also shows the approximate altitude corresponding to each
  isobar in the current pressure setting.
  :::
::

Entering a page with EDL overlay resets the display to the next UTC
forecast hour and enables auto advance.  The overlay legend in the upper
right corner shows the active local forecast hour, the selected pressure
level and its approximate altitude.

The same EDL overlay can be enabled on any map page by setting
*Map overlay* to *EDL* in the page configuration.

The EDL source is intended for wave flying and provides rendered image
tiles rather than raw meteorological grids.  XCSoar therefore uses the
EDL imagery as a map overlay and does not expose additional model
parameters beyond the forecast hour and the fixed isobar levels
published by the EDL service.
