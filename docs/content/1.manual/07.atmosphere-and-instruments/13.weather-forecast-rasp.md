---
title: Weather forecast, RASP
description: Displaying RASP soaring forecasts as map overlays, the RASP setup options and the available fields.
---

Regional Atmospheric Soaring Prediction (RASP) is intended to provide
detailed graphical weather forecasts for soaring purposes. For further details
the pilot is invited to consult http://www.drjack.info on how RASP
forecasts work, from where they are available, and their use and limitations.
RASP forecasts use a specialized forecast model with a particular focus on
boundary layer (BL) meteorology and convective processes.

You can find a list of available RASP forecasts at http://www.drjack.info/RASP.
These are provided by various independent soaring and paragliding enthusiasts.
Please note that some of these links provide data in-season only, and only some
of these providers make data available in XCSoar format.

You can either install RASP data files yourself, or use XCSoar’s built-in
automatic download for many regions worldwide via the ‘Site Files / Site Files’
configuration page, [Site Files](/manual/configuration/site-files), or
the *Update* button in Info → Weather → RASP.  In that RASP panel,
*Auto update* (on by default) also refreshes an out-of-date or missing
file when you open a RASP map page or when auto time has no data; turn it
off for offline use.

The files have `.dat` extension and the information is shown
as colour-coded terrain overlays on the map.

::tip
Make sure that terrain display is set to “on”.
::

The main configuration dialog for RASP is in the weather setup via menu
`RASP`.
You select the RASP data file to display, and the data field to be shown.
After choosing the the configuration, use `Assign to page` to
assign that configuration to the current map page.

`Info` → `Weather Setup`

Alternatively, you can control which pages show weather data and how weather
display is controlled via the page configuration (Section
[Look / InfoBox Pages](/manual/configuration/look#look-infobox-pages-or-just-pages)):
Set *Map overlay* to *RASP*,
choose the *RASP layer* for that page, and optionally set the
*Bottom area* to *Weather controls* for in-flight forecast time
control. This allows configuration of several pages quickly.

![Weather dialogue](/img/figures/dialog-weather.png)

When the bottom *Weather controls* panel is visible, *Auto advance*
follows the current local time.  Turn it off to select a
fixed forecast time. When entering a page with RASP overlay for the first
time, XCSoar selects the next forecast time in the RASP file at or after the
current time.

When a field is not available in the RASP file, the background is left blank.
The current field name is displayed in the lower left corner of the screen
whenever RASP data is displayed.

RASP display configuration parameters are in the `RASP` tab in
`Info` → `Weather Setup`. Global options are:

::field-group
  :::field{name="File"}
  Shows the currently selected RASP data file and allows selection
  and download of other RASP data files.
  :::

  :::field{name="Modified"}
  Shows the last modification date of the currently selected RASP data file.
  :::

  :::field{name="Update"}
  Attempts to download the latest version of the currently selected RASP data
  file. This is available for RASP data files that were downloaded from the
  XCSoar repository. THe download is in the background, the data will
  automatically update once it is completed.
  :::

  :::field{name="Layer"}
  Selects the RASP data field to display on the currently active map page,
  indicated above the layer field.
  :::

  :::field{name="Colormap"}
  Below the layer selector, a colormap preview is shown for the currently
  selected RASP data field, with the scale given in the currently selected
  units.
  :::

  :::field{name="Contours"}
  Allows activation/deactivation of contour lines in the weather data,
  as well as the density of the contour lines.
  :::

  :::field{name="Opacity"}
  Allows adjustment of the opacity of the weather overlay. Some weather layers
  are global and do not have a transparency channel, such as the surface
  temperature. This setting allows to make them partially transparent to enable
  the underlying terrain to shine through.  
  For RASP layers with their own transparency souch as wave lift or cloud
  cover, this setting only reduces opacity, it never overrides the transparency
  of that layer.
  :::

  :::field{name="Assign to page"}
  Assigns the currently selected RASP configuration to the currently
  active map page.
  :::

  :::field{name="Add page"}
  Creates a new map page with the currently selected RASP configuration after
  the currently active page.
  :::
::

The available fields can vary by data source. Some examples include:

::field-group
  :::field{name="Wave"}
  Vertical velocity of the air mass at the given altitude.

  ![RASP wave](/img/figures/rasp-wave.png)
  :::

  :::field{name="Rain"}
  Predicted preciptation rate integrated over the forecast step interval
  (typically 15 minutes or 1 hour).

  ![RASP rain](/img/figures/rasp-rain.png)
  :::

  :::field{name="W*"}
  Average dry thermal updraft strength near mid-BL height.  Subtract
  glider descent rate to get average vario reading for cloudless
  thermals.  Updraft strengths will be stronger than this forecast if
  convective clouds are present, since cloud condensation adds buoyancy
  aloft (i.e. this neglects “cloudsuck”).  This value depends upon both
  the surface heating and the BL depth.

  ![RASP W*](/img/figures/rasp-wstar.png)
  :::

  :::field{name="BL wind spd"}
  The speed and direction of the vector-averaged wind in the boundary layer.
  This prediction can be unreliable if there is large wind shear through the
  BL.

  ![RASP BL wind speed](/img/figures/rasp-blwindspd.png)
  :::

  :::field{name="H bl"}
  Altitude of the top of the mixing layer, which for thermal convection is
  the average top of a dry thermal.  Over flat terrain, maximum
  thermalling heights will be lower due to the glider descent rate and
  other factors.  In the presence of clouds (which release additional
  buoyancy aloft, creating “cloudsuck”) the updraft top will be above
  this forecast, but the maximum thermalling height will then be limited
  by the cloud base.  Further, when the mixing results from shear
  turbulence rather than thermal mixing this parameter is not useful for
  glider flying.

  ![RASP H bl](/img/figures/rasp-hbl.png)
  :::

  :::field{name="dwcrit"}
  This parameter estimates the height above ground at which the average
  dry updraft strength drops below 225 fpm (1.1 m/s). This is expected to give
  better quantitative numbers for the maximum cloudless thermalling
  height than the BL Top altitude, especially when mixing results from
  vertical wind shear rather than thermals.  (Note: the present
  assumptions tend to underpredict the max. thermalling height for dry
  conditions) In the presence of clouds the maximum thermalling height
  may instead be limited by the cloud base.
  :::

  :::field{name="hwcrit"}
  Same as *dwcrit*, but giving the altitude instead of the height at which
  the average dry updraft strength drops below 225 fpm.
  :::

  :::field{name="bl cloud"}
  This parameter provides an additional means of evaluating the
  formation of clouds within the BL, and might be used either in
  conjunction with or instead of the other cloud prediction parameters.
  It assumes a very simple relationship between cloud cover percentage
  and the maximum relative humidity within the BL.  The cloud base
  altitude is not predicted, but is expected to be below the BL top
  altitude.

  ![RASP BL cloud](/img/figures/rasp-blcloudpct.png)
  :::

  :::field{name="Sfc temp"}
  The temperature at a height of 2 m above ground level.  This can be
  compared to observed surface temperatures as an indication of model
  simulation accuracy; e.g. if observed surface temperatures are
  significantly below those forecast, then soaring conditions will be
  poorer than forecast.
  :::

  :::field{name="wblmaxmin"}
  Maximum grid-area-averaged extensive upward or downward motion within
  the BL as created by horizontal wind convergence. Positive convergence
  is associated with local small-scale convergence lines.  Negative
  convergence (divergence) produces subsiding vertical motion, creating
  low-level inversions which limit thermalling heights.
  :::

  :::field{name="blcwbase"}
  This parameter estimates the altitude of the cumulus cloud
  base.
  :::
::
