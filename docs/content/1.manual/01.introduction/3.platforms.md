---
title: Platforms
description: The platforms XCSoar runs on, from Android devices and Kobo eReaders to Windows and Unix/Linux PCs.
---

::field-group
  :::field{name="Android Devices"}
  XCSoar runs on Android 6.0 or newer.
  :::

  :::field{name="eBookreader"}
  XCSoar runs on several Kobo eReader devices.
  :::

  :::field{name="Windows PC"}
  It is possible to run XCSoar on an ordinary computer with the Windows
  operating system (Vista and above). This setup can be used for training
  yourself in using XCSoar. A simulation mode is included in XCSoar as well as
  a IGC replay function, that can be used when not connected to a valid GPS
  source.
  :::

  :::field{name="Unix/Linux PC"}
  XCSoar runs on Unix/Linux.
  :::
::
