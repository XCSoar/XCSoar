As of version 6.0, XCSoar supports so-called *gestures*.

To use this feature hold down the finger on the touch-screen (or mouse button at
the PC), draw a certain figure and release the touch-screen / mouse button.
Depending on the figure that was drawn a certain function is activated.

![Gesture](/img/figures/gesture1.png)

::gesture-aside{id="DR"}
A specific gesture is defined by movements of the finger or the cursor in the
four directions Up, Down, Left and Right. This means if you drag your finger
down and afterwards to the right over the screen, the gesture `DR` is detected,
which stands for “Down-Right”. It will bring up the waypoint list. The manual
indicates an available gesture as shown here on the left side of the text body.
Both the blue hand and pictogram of the movement are used to indicate a specific
gesture, in this case move down then to the right. A list of generally available
gestures is shown below.
::

| Figure | Gesture | ID | Character | Function |
|:-:|---|---|:-:|---|
| :gesture{id="U"} | Up | `U` | | Zoom in |
| :gesture{id="D"} | Down | `D` | | Zoom out |
| :gesture{id="R"} | Right | `R` | | Previous screen page |
| :gesture{id="L"} | Left | `L` | | Next screen page |
| :gesture{id="UD"} | Up-Down | `UD` | | Auto zoom |
| :gesture{id="DU"} | Down-Up | `DU` | ✓ | Main menu |
| :gesture{id="DR"} | Down-Right | `DR` | L | Waypoint **l**ist |
| :gesture{id="DL"} | Down-Left | `DL` | | Alternates |
| :gesture{id="LU"} | Left-Up | `LU` | | Recently used waypoints |
| :gesture{id="RD"} | Right-Down | `RD` | T | **T**ask manager |
| :gesture{id="URD"} | Up-Right-Down | `URD` | A | **A**nalysis |
| :gesture{id="LDR"} | Left-Down-Right | `LDR` | C | **C**hecklist |
| :gesture{id="URDL"} | Up-Right-Down-Left | `URDL` | P | **P**an mode |
| :gesture{id="LDRDL"} | Left-Down-Right-Down-Left | `LDRDL` | S | **S**tatus |
| :gesture{id="ULDR"} | Up-Left-Down-Right | `ULDR` | Q | **Q**uick menu |

Pan mode might also be invoked by moving two fingers on the screen. On
touchscreens that report both finger positions (Android, iOS), pinching zooms
the map about the point between the fingers, and twisting rotates it
temporarily. A two-finger drag or twist enters pan mode, and the temporary
rotation is held until pan mode is left; a pinch that only zooms keeps following
the aircraft.
