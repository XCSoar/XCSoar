---
title: Thermal next leg equivalent
description: The T Next Leg InfoBox, which translates the current MacCready performance onto the next task leg.
---

The `T Next Leg` InfoBox shows the climb on the next task leg
that gives the same average cross-country speed as flying the current
leg at the MacCready setting.  The calculation uses the glide polar and
the headwind component on each remaining track.  The box is blank when
there is no valid next leg, no wind, or no polar.  The comment shows
“no wind” when wind is not available.

Compared with the MacCready setting:

* A lower value means the next leg is easier (typically a turn from
  into-wind to downwind).  Weaker thermals after the turn can still
  match the present average speed.
* A higher value means the next leg is harder (typically a turn
  into wind).  Extra height before the turn, and less selective
  thermalling afterwards, help hold the present average.
* A similar value means the wind on both legs is comparable.

This is not a MacCready setting.  MacCready remains the expected lift;
T Next Leg only translates that performance onto the next track.
