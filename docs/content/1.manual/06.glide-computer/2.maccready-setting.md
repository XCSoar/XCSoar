---
title: MacCready setting
description: The ways of adjusting the MacCready setting by InfoBox, connected variometer or automatically.
---

The MacCready setting may be adjusted several ways:

* For touchscreen/mouse devices, select the MacCready InfoBox field, then
  use the up and down arrow keys.
* When connected to a supported intelligent variometer, adjusting
  the MacCready setting on the variometer will change the setting
  in XCSoar according to the devices synchronisation configuration (see
  Section [Configure Devices](/manual/configuration/configure-devices))

In addition, an automatic MacCready mode is available as described in
Section [Auto MacCready](/manual/glide-computer/auto-maccready).
