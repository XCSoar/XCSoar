title: File management
description: The two categories of data files, where they are stored and the XCSoarData directory.
---

Data files used by XCSoar fall into two categories:

::field-group
  :::field{name="Flight data files"}
  These files contain data relating to the aircraft type, airspace and maps,
  waypoints etc. These are the files that are most likely to be modified or set
  by normal users.
  :::

  :::field{name="Program data files"}
  These files contain data relating to the look and feel of the program, button
  assignments, input events.
  :::
::

This chapter focuses on flight data files; see the *XCSoar Advanced
Configuration Guide* for details on program data files.

File names must correspond to the name extensions specified below. It is good
practice to make sure that the file names are recognisable so that when making
configuration changes there is less risk of confusion between different files
and different file types.

Terrain and topography files are accessed continuously while XCSoar is running,
so they should be located on reasonably fast storage. Modern memory cards
usually meet the required performance.

All data files should be copied into the directory `XCSoarData`. See
[Installation](/manual/installation/software-installation) for where that
directory lives on each platform.

If unsure, just start the newly installed XCSoar and it creates the `XCSoarData`
directory at the right place.
