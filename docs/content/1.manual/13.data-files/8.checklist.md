---
title: Checklist
description: The checklist file format with up to 32 named pages of free text.
---

The checklist file (`xcsoar-checklist.txt`) uses a similar format to
the airfield details file.  Each page in the checklist is preceded by
the name of the list in square brackets.  Multiple pages can be
defined (up to 32).

An example (extract):

```
[Preflight]
Controls
Harness, secure objects
Airbrakes and flaps
Outside
Trim and ballast
Instruments
Canopy

[Derigging]
Remove tape from wings and tail
...
```
