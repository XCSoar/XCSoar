---
title: Tasks
description: The XCSoar task file format and loading SeeYou tasks.
---

Task files (extension `.tsk`) are stored in XCSoar’s own XML format,
whereas SeeYou tasks can also be loaded from file (extension `.cup`).
The task file format is documented for developers and authors of
converters at https://xcsoar.readthedocs.io/en/latest/task_file.html.
